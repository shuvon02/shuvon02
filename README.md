## 🚀 About Me

I am a dedicated **Software Engineer** specializing in **Java Backend Development** and **Modern Native Android (Kotlin)**. I love dissecting complex problems, engineering scalable software architectures, and turning ideas into clean, user-friendly digital experiences.

- 🔭 **What I Do**: Architect robust RESTful APIs with **Spring Boot** and build reactive, offline-first mobile apps with **Kotlin & Jetpack Compose**.
- 🌱 **Continuous Learning**: Currently exploring microservices architecture, cloud deployment, and system design patterns.
- 💬 **Ask Me About**: Java, Spring Boot, Spring Security, Android SDK, Room SQLite, Database Optimization, and OOP.
- ⚡ **Philosophy**: *"Clean code always looks like it was written by someone who cares."*
