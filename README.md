## 🚀 About Me

I am a dedicated **Software Engineer** specializing in **Java (Spring Boot)** and **C / C++**. I love dissecting complex algorithmic problems, engineering robust backend systems, and building scalable, high-performance software solutions.

- 🔭 **What I Do**: Architect secure RESTful APIs and backend microservices with **Spring Boot**, and write efficient, memory-optimized algorithms and system programs in **C / C++**.
- 💡 **Core Strengths**: Object-Oriented Programming (OOP), Data Structures & Algorithms, Multithreaded Socket Networking, and Database Design.
- 🌱 **Continuous Learning**: Advanced system design, distributed backend architectures, and performance optimization.
- 💬 **Ask Me About**: Java, Spring Boot, Spring Security, Hibernate/JPA, C, C++, Data Structures, Multi-threading, and Relational Databases.
- ⚡ **Philosophy**: *"Clean code always looks like it was written by someone who cares."*
